# Extensions

One folder per extension. Each folder holds the extension's files, its `.trex` file and a README with what it does, what data it needs, and the address your Tableau admin may need to allow.

| Extension | What it does |
|---|---|
| [small-multiples](small-multiples/) | One small bar chart per region (or any field), with variance, so the good and the bad stand out at a glance |
