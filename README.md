# The Insights Collective toolkit

Tableau extensions, Claude skills and other resources from The Insights Collective and The grAI Team, made for our members and anyone else who finds them useful.

## What's here

- **[extensions/](extensions/)**: Tableau viz extensions you can add to your own workbooks. Each one has its own folder and its own README.
- **[skills/](skills/)**: Claude skills we share. None yet.
- **[resources/](resources/)**: templates, prompts and handouts. None yet.

## Using an extension

Download its `.trex` file. In Tableau, on the Marks card, choose Add Extension, then Access Local Extensions, and pick the file. On Tableau Server or Cloud your admin may need to allow the extension's address first; each extension's README gives the exact address.

Free to use. Provided as is, with no warranty.
